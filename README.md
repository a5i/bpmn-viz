# BPMN Rust prototype

MIT-licensed proof of concept for parsing BPMN 2.0 XML and rendering BPMN DI to SVG/PNG.

**Status:** architecture/scaffold, implementation not started. See [specification](docs/specifications/SPEC-001-bpmn-renderer.md).

The repository is documentation-first: tasks, ADRs and evidence are Markdown artifacts. DocVera integration requires verification against the installed version before wiring commands into CI.
