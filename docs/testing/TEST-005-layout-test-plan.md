## Assertions

- **Contracts (`contracts.rs`):** option validation (finite, nonnegative; unsupported combinations rejected with stable codes), `unknown_scope` on wrong id, M1 warning coverage (unsupported elements skipped with warnings, never invented nodes), `LayoutOutcome.diagram` carries plane bound to the selected process.
- **Geometry invariants (`geometry_invariants.rs`), run for every accepted fixture:** exactly one shape per supported flow node and one edge per sequence flow; no extra or bogus shapes; shape bounds finite with positive size; ≥2 ordered waypoints per edge, finite and axis-aligned between consecutive waypoints; first/last waypoint docks on source/target boundary; no edge segment enters an unrelated shape interior; no two flow-node shapes overlap; generated coordinates are integers.
- **Determinism (`determinism.rs`):** three consecutive layouts of the same input produce byte-identical canonical geometry and identical warning order; layout does not mutate the semantic document (authored diagrams, if any, unchanged); layouting a structurally equal model built in a different collection order (same declaration order) yields identical geometry.
- **Errors (`errors.rs`):** fixtures 9–10 return the documented stable codes; no panic under `cargo test`; resource limits (`LayoutLimits`) reject oversized scopes with `layout.limit_exceeded`; property test generates random malformed models (dangling refs, self loops, duplicate ids, huge gaps) and asserts `layout()` always returns `Ok`/`Err` without panic.
- **Errors (`errors.rs`):** fixtures 9–11 return the documented stable codes; no panic under `cargo test`; resource limits (`LayoutLimits`) reject oversized scopes with `layout.limit_exceeded`; property test generates random malformed models (dangling refs, self loops, duplicate ids, huge gaps) and asserts `layout()` always returns `Ok`/`Err` without panic.
- **Differential (`reference_parity.rs`):** for each applicable fixture, native and reference canonical representations agree on: element coverage (same shape/edge id sets), topology (same flow source→target relations), containment (single plane, no unexpected nesting), orthogonal routing (all segments axis-aligned), collision freedom (no route through unrelated shapes). Coordinates may differ.
- **Stress coverage (`complex.rs`):** each complex fixture lays out with exactly its documented warnings (only `c20-subprocess-cascade` emits `layout.subprocess_body_skipped` — no silent skips anywhere in the class); the accepted double diamond covers 17 shapes / 22 edges without warnings while its loop-only variant is pinned as failure 11; wide fan-in channels land on separated rows; the long pipeline spine stays left-to-right monotonic.
- **Consumability (workspace integration test):** for each accepted fixture, `bpmn_render::render_diagram` builds a scene from the generated `Diagram`, `bpmn_svg::to_svg` produces deterministic SVG containing every node id, and `bpmn-raster` renders a nonempty PNG; rendering a no-DI document through the unchanged renderer still fails with `di.missing_interchange` (Preserve regression, ADR-0007).

## Coverage

- Scope extraction and validation: duplicate node ids, missing/cross-scope endpoints, unsupported element skipping (warnings), artifact/lane/subprocess-body separation.
- Semantic analysis: components, start selection policy, spine choice (reachable-to-end → default → declaration order), back edges, ranks (longest path), band assignment (spine band 0; no-default alternatives alternate below/above; default-flow alternatives fan one side), join handling.
- Placement: rank columns (widest-node width, centered), band rows, same-rank/band stacking, component stacking, margin normalization, integer output.
- Routing: straight spine edges, cross-band elbows with channel search, long edges across occupied ranks, feedback (loop-back) outer channels, docking distribution for parallel joins, segment cleanup, `layout.routing_failed` on impossible routes.
- Output: DI shape/edge ids and semantic association, verifier invariants, renderer/raster consumability, Preserve-mode regression.
- Not covered in M1: subprocess bodies, boundary events, lanes, collaborations, message flows, artifacts, label bounds (M2/M3), coordinate equality with the reference (explicitly out of contract), pixel-equality against other renderers (ADR-0004).
- Stress class (`complex/`): realistic wide fan-in/fan-out, cascades, scrambled declaration and cross-band topologies — invariants, determinism, warning contract and consumability (no frozen coordinates, no reference parity).

## Exit Criteria

- `cargo test -p bpmn-layout` green (contracts, invariants, determinism, errors, snapshots, differential, property).
- `cargo test --workspace` green including the renderer consumability suite.
- `cargo fmt --all -- --check` and `cargo clippy --workspace --all-targets -- -D warnings` clean.
- `docvera check` exits 0 (EPIC-005/TASK-018/ADR-0006/ADR-0007/EXP-004/TEST-005 validate).
- `cargo deny check` green with the new dev-dependencies (`serde`, `serde_json`, `proptest`, `criterion`) recorded in EXP-004.
- Benchmark corpus (10/100/1,000 nodes) executed once on a fixed runner with medians recorded in EXP-004; no invented thresholds.
